From this web page you can download renderings of the [ACM SIGMOD](http://www.acm.org/sigmod/) logo in different sizes and formats. You may use the [ACM SIGMOD](http://www.acm.org/sigmod/) logo provided that:

-   You use one of the official logo available at [http://www.acm.org/sigmod/sigmod-logo](http://www.acm.org/sigmod/sigmod-logo/index.html).
-   You do not modify them in **any** way.
-   They are used to decorate you personal academically oriented web page (the page should be hosted at your institution).
-   They are used to decorate a conference (or similar event) page which is being held in-cooperation with [ACM SIGMOD](http://www.acm.org/sigmod/) or is being formally supported/sponsored by [ACM SIGMOD](http://www.acm.org/sigmod/). In this case, you need to either wait until formal approval is secured or add the expression “(pending)”.
-   The logo must link to [http://www.acm.org/sigmod/](http://www.acm.org/sigmod/).
-   Any other use does require explicit permission from one of the [ACM SIGMOD officers](https://sigmod.org/about-sigmod/sigmod-logo-renderings/about%20sigmod.html "About SIGMOD") (Chair, Vice-Chair, or Treasurer).

Drawing and image editing was done using the [CorelDRAW 8](http://www.corel.com/) package, academic version. The text font in the logo is Aardvark Bold by [Gerard Bernor](mailto:KidBayou@aol.com), downloaded from [Font Freak](http://www.fontfreak.com/). PostScript was generated by [Mayura Draw 3.1](http://www.mayura.com/).  
All files accessible from this page are also available in this [directory](https://sigmod.org/about-sigmod/sigmod-logo-renderings/sigmod-logo/archive/index.html) or as a single [.tar.gz file](/wp-content/uploads/2015/07/sigmod-logo.tar_.gz). In the directory you can also find the CorelDRAW 8 files (.cdr) that I used to create the logo, plus other goodies. Please read the file [README](https://sigmod.org/about-sigmod/sigmod-logo-renderings/sigmod-logo/archive/README.html) for an explanation of the directory structure.
