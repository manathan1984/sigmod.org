The software systems and tools listed below were announced to be available free of charge  
– at least as beta releases and at least for academic and/or personal use.

See instructions at the end of the page on how to submit new  
entries to the list or to correct existing entries. Also report when a package is  
no longer available free of charge.

**OUTDATED DOCUMENT!**

[AMOS-II](http://www.dis.uu.se/~udbl/amos/)

An extensible, main-memory, Object-Oriented (OO), and  
distributed multi-database system from University of Uppsala.

[ASES](http://www.cis.njit.edu/~jason/sigmod.html)

Approximate Search Engines for Structure,  
software for approximate searching  
for patterns in tree (e.g. XML, hierarchies)  
and graph (e.g. chemical) data.  
In addition, some software for data mining and clustering.

[Berkeley Database](http://www.sleepycat.com/)

Open source DBMS for embedded systems,  
originally developed at Berkeley; download and use free but not re-distribution.

[BKD](http://kmi.open.ac.uk/projects/bkd/)

Bayesian  
Knowledge Discoverer, a program designed to extract Bayesian Belief  
Networks (BBNs) from (possibly incomplete) databases.

[BIM Standard Edition](http://bimopensourcesolutions.freewebspace.com/)

Free DBMS by Matthew Farhat that organizes text and arithmetic equations;  
includes organizational user specified template hierarchy, GUI, cross-table spreadsheets,  
search engine, documentation, and internet sockets.

[BKD](http://kmi.open.ac.uk/projects/bkd/)

Bayesian Knowledge Discoverer, a program designed to extract Bayesian Belief Networks (BBNs) f  
rom (possibly incomplete) databases.

[ChronoLog](https://sigmod.org/publications/sigmod-record/databaseSoftware/chronolog.txt)

Interval  
timestamped temporal deductive database system running as a frontend to  
the commercial (relational) database system Oracle.

[ConceptBase](http://www-i5.informatik.rwth-aachen.de/CBdoc/cbflyer.html)

A multi-user meta data repository system with a graphical user interface  
that allows to engineer customized modeling environments via its logic-based  
meta-modeling capabilities.

[Coral](ftp://ftp.cs.wisc.edu/coral)

Root directory for Coral deductive DBMS from Wisconsin.

[Datalog++](http://www.cs.msstate.edu/~sbase/datalog/win-datalog/)

Deductive and object-oriented database system from Mississippi  
State University. [Demo](http://www.cs.msstate.edu/~sbase/datalog/) also available.

[DB-MAIN](http://www.info.fundp.ac.be/~dbm)

A Windows CASE tool supporting most DB engineering processes from  
University of Namur. Supports most current conceptual and physical models.

[db4o](http://www.db4o.com/)

db4o – database for objects – is a Java object database.  
The free edition is redistributable in non-commercial applications.

[EOS](ftp://ftp.research.att.com/dist/eos)

AT&T; Bell Laboratories’ Storage Manager.

[Exodus](ftp://ftp.cs.wisc.edu/exodus)

Root directory for Exodus (DBMS substrate) from Wisconsin.

[Firebird](http://firebird.sourceforge.net/)

Open source relational database offering many ANSI SQL-92 features.  
Runs on Linux, Windows, and a variety of Unix platforms.

[FLORID](http://www.informatik.uni-freiburg.de/~dbis/florid/)

A Deductive Object Oriented Database System implementing F-Logic, developed at the University of Freiburg.

[GADFLY](http://www.chordate.com/kwParsing/gadfly.html)

ODBC 2.0 SQL implementation with recovery and secure TCP/IP client/server access modes.

[GiST](http://gist.cs.berkeley.edu/)

Generalized  
Search Tree (GiST) software, developed at UC Berkeley, allows  
researchers to quickly develop and experiment with indexing schemes for  
new data types.

[GSTD](http://db.cs.ualberta.ca:8080/gstd)

The GSTD algorithm generates sets of moving (point or rectangular)  
objects to benchmark spatio-temporal DBMSs. Includes source code and a visualization tool for  
implementing various scenarios.

[H-PCTE](http://pi.informatik.uni-siegen.de/pi/hpcte/hpcte.html)

High-performance  
implementation of the distributed object management system specified in  
the international PCTE standards ECMA-149/158 and ISO 13719.

[Ingres](http://control.cs.berkeley.edu:8000/ingres/)

Berkeley FTP directory containing 1989 Ingres tar file.

[InterBase](http://www.interbase.com/index.html)

Rather complete RDBMS (SQL, ACID,…) that is now developed in an open  
source framework.

[LEAP](http://leap.sourceforge.net/)

An Extendable Relational Algebra Processor.

[LINCKS](ftp://ftp.ida.liu.se/pub/lincks/INDEX.html)

Multi-user object-centred database system developed around 1994  
at the University of Linkoping.

[Mariposa](http://epoch.cs.berkeley.edu/mariposa/index.html)

Distributed Database Management System from UC Berkeley.

[Mckoi SQL Database](http://www.mckoi.com/database/)

Mckoi SQL Database is a complete SQL management system  
written entirely in Java. It can operate as a multi-threaded multi-user  
database server or embedded in a Java application. Released under the  
GPL open source license.

[MetaKit](http://purl.net/meta4/metakit)

C++ class library for persistent structured data.

[METU](http://www.srdc.metu.edu.tr/mood/)

Object-Oriented DBMS (MOOD) from Turkey.

[MIND](http://www.srdc.metu.edu.tr/mind/index.html)

Multidatabase system using Oracle7, Sybase, Adabas D and MOOD, implemented on top of DEC’s ObjectBroker CORBA implementation.

[MultiCal](ftp://ftp.cs.arizona.edu/tsql/multical)

A  
system from the University of Arizona that supports the management of  
multiple calendars, through temporal extensions to SQL. A main-memory  
DBMS is also available that can be used as a substrate for the calendar  
system.

[mySQL](http://www.mysql.com/)

Popular Open Source SQL database system.

[OCELOT SQL](http://www.ocelot.ca/download.htm)

An SQL DBMS distributed under Mozilla/GPL licence. Includes SQL engine,  
ODBC interface, front end, samples and documentation and complete source code.

[OLE DB](http://www.microsoft.com/data)

OLE  
DB is a freely published specification and Software Development Kit  
(SDK) designed with industry-wide participation for data access to  
diverse information sources, regardless of location or type.

[OSDB](http://osdb.sourceforge.net/)

The Open Source Database Project develops a database benchmark suite based on the AS3AP benchmark  
which anyone can download and use to test/optimise their hw/sw combination (SQL-based).

[OO7 Benchmark](ftp://ftp.cs.wisc.edu/OO7)

OO7 benchmark from Wisconsin.

[Orient ODBMS](http://www.orientechnologies.com/)

A light object server that is ODMG 3.0 compliant. Beta version is free for  
non-commercial use (see license terms).

[Ozone](http://www.ozone-db.org/ozone_main.html)

An object-oriented database management system completely implemented in  
Java and distributed under an open source license.

[Phasme](http://www.rd.nacsis.ac.jp/~andres/db/phasme.html)

Application-oriented Micro-kernel DBMS which supports parallel and active features.

[picoSQL](http://www.picosoft.it/picosql)

Open-source SQL database system originally derived from a commercial  
product.

[Postgres](http://db.cs.berkeley.edu/postgres.html)

Object-relational DBMS (last Berkeley release).

[PostgreSQL](http://www.postgresql.org/index.html)

Web-supported public-domain successor to Berkeley Postgres.

[  
Predator](http://www.distlab.dk/predator)

PREDATOR is an object-relational database system developed at Cornell  
University and now maintained at University of Copenhagen.  
PREDATOR is supported as a research and educational tool.  
Source code is available.

[Relationlog 1.0](http://www.cs.uregina.ca/~mliu/RLOG)

A  
persistent deductive database system from the University of Regina in  
Canada. Supports inference on nested and complex-object relations with  
declarative semantics.

[ROCK & ROLL](http://www.cee.hw.ac.uk/Databases/rnr.html)

Deductive  
Object Oriented Database System developed by the Department of  
Computing & Electrical Engineering at Heriot-Watt University.

[ROL](http://www.cs.uregina.ca/~mliu/ROL/index.html)

Rule-based Object Language is a deductive object-oriented database system developed at the University of Regina in Canada.

[SAP DB](http://www.sapdb.org/index.html)

SQL-based DBMS from SAP with object-oriented extensions distributed under GNU General Public Licence (kernel)  
and GNU Lesser General Public License (client, programming interface).

[Shore](http://www.cs.wisc.edu/shore/index.html)

Object-oriented database system developed at the University of Wisconsin–Madison.

[SQLite](http://www.hwaci.com/sw/sqlite/)

Free and open-source SQL database server delivered as a library of C routines.  
Sources are not copyrighted and may be used for any purpose (as the home page says).

[Texas Persistent Store](ftp://ftp.cs.utexas.edu/pub/garbage)

Root directory for the Texas Persistent Store, a DBMS that has a memory-mapped architecture similar to that of ObjectStore.

[ThinkSQL](http://www.thinksql.co.uk/)

ThinkSQL is a relational database server aiming at full ISO SQL compatibility.  
Beta version is free for download.

[VisDB](http://www.informatik.uni-halle.de/dbs/Research/VisDB/visdb.html)

The VisDB system is a visual data mining techniques, which allows an  
exploration of large databases.

[VODAK](http://www.darmstadt.gmd.de/oasys/projects/vodak/index.html)

Object-oriented database management system that was developed over the past years at GMD-IPSI.

[W3QS](http://www.cs.technion.ac.il/~W3QS)

W3QS is a query system for the WWW.

[WebSQL](http://www.cs.toronto.edu/~websql)

WebSQL is a declarative query language that helps automate Web navigation and search.

[WinRDBI](http://www.eas.asu.edu/~cse412/winrdbi.html)

The Windows-based Relational Database Educational Tool  
provides students with a hands-on approach to learning the formal  
query languages and SQL-89.

[WinSQL Lite](http://www.indus-soft.com/winsql/)

A user interface for SQL-based DBMSs that connects via ODBC to  
any kind of target database server. Lite version is free of charge.  
This tool is meant for database administrators.

[XDb](http://www.xdb1.com/)

Object-oriented database for Windows and PocketPC. “Instantiate, reference,  
copy, cut, paste, delete objects with the ease of File Explorer like GUI.”  
ActiveX DLL interface compatible with VB, C, Delphi, ASP.

[XSB System](http://xsb.sourceforge.net/)

Prolog-based  
XSB deductive database system originated at SUNY Stony Brook. Includes  
a datalog interpreter, support for HiLog terms, and support for the  
well-founded semantics.

[Xplain](http://www.pobox.com/~berend/xplain)

Xplain2sql translates the Xplain database definition and manipulation  
language to various SQL dialects including ANSI, InterBase, TransactSQL  
and PostgreSQL.

[XQL](http://xml.darmstadt.gmd.de/xql/)

The GMD-IPSI XQL engine is a Java based database for native XML documents.  
It uses a persistent W3C DOM for storage and XQL’98 for queries. Free for  
personal and academic use.

Additional  
available systems, including short text summaries, can be found by  
looking in the compilation of vendors and prototype systems in the [comp.object FAQ](http://www.cyberdyne-object-sys.com/oofaq2/).
